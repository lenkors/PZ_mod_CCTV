## [0.1.0-alpha] - Кабачок

Alpha релиз - CCTV Base для Project Zomboid (Build 42).

### Добавлено
- **Предметы CCTV**:
  - `CameraItem` — видеокамера CCTV (категория Electronics).
  - `RepeaterItem` — ретранслятор сигнала CCTV (категория Electronics).
- **Установка оборудования**: возможность установить камеру или ретранслятор из инвентаря на текущей клетке игрока (пункт контекстного меню инвентаря). При установке предмет удаляется из инвентаря.
- **Менеджер камер (`CCTV_Manager`)**:
  - Регистрация камер и ретрансляторов с координатами.
  - Расчёт дистанции и базового радиуса приёма сигнала без ретранслятора (`MAX_DEFAULT_DIRECT_RANGE = 30`).
  - Проверка наличия ретранслятора в радиусе для расширения дальности связи.
  - Получение списка доступных камер для конкретного телевизора с расчётом условного уровня сигнала.
- **Подключение к CCTV через телевизор**: пункт контекстного меню "Подключиться к CCTV" появляется при взаимодействии с телевизором (`IsoTelevision`), если поблизости есть доступные камеры.
- **Интерфейс просмотра камер (`CCTV_UI`)**:
  - Полноэкранный UI с переключением между камерами (кнопки "Пред." / "След.").
  - Отображение имени камеры, условного уровня сигнала и порядкового номера текущей камеры.
  - Кнопка отключения от CCTV с возвратом камеры игрока в обычный режим.
  - Сообщение об отсутствии сигнала, если камеры не найдены.
- **Локализация (`CCTV_i18n`)**: базовые строки интерфейса (частично на русском, частично на английском).

### Известные ограничения
- Локализация не разделена по языковым файлам игры (`Translate`), строки захардкожены в `CCTV_i18n.lua`.
- Отсутствует проверка электропитания/долговечности камер и ретрансляторов.
- Расчёт дальности сигнала упрощённый (без учёта стен/этажей).
